# Changelog

格式基于 [Keep a Changelog](https://keepachangelog.com/)，版本号遵循 [Semantic Versioning](https://semver.org/)。

## [0.2.4] - 2026-10-17

### 模型接入

- 自定义服务商新增 OpenAI Responses 类型，支持文字、图片和工具调用，可配置接口路径拼接并拉取模型列表。

### 聊天上下文

- 修复历史图片和文件被追加到最新消息的问题，保留附件、引用及群聊发言者的对应关系，完善角色所发图片的历史上下文。
- 私聊与群聊支持保存识图、文件读取、MCP 和本地插件的工具调用记录，后续对话可读取调用参数、结果和状态。

### 图片生成与识别

- 生图、截图等工具返回的图片可在同一轮继续识别，支持视觉模型直接读取及通过识图工具查看。
- 优化生图提示词与尺寸选择指引，根据用户要求、画面构图和模型接口选择画幅，完善角色形象与参考图使用说明。

## [0.2.3] - 2026-10-13

### Web 多角色群聊

- 新增多角色群聊，支持文字、图片、文件、引用、表情、语音回复、生图与工具调用，可管理成员、群头像和聊天历史。
- 支持 `@成员`、`@所有人` 和角色互相点名接话；引用角色消息时自动 @ 原发送者，优化角色对发言者与对话对象的识别。
- 可设置成员回复概率、连续回复上限，并手动停止接话；用户发言后无人接话时，从回复概率大于 0 的成员中按权重选择一位回应。
- 支持群共同背景、聊天规则和成员专属提示词，以及后台接话、刷新重连和群设置草稿恢复。

### 群聊记忆

- 每群每角色拥有独立记忆，可单独开关生成、查看、编辑和删除，并按角色设置读取私聊记忆。
- Web、微信和 QQ 私聊可按群选择读取角色的群聊记忆；离群后保留记忆，删除群聊时可选择一并清理。
- 优化记忆总结与整理的调用顺序，修复清空记忆、关闭生成或删除角色后旧任务再次写入的问题。

### 语音

- 新增 ElevenLabs 语音服务商，支持 Eleven v4、MP3 试听、账户音色搜索与分页、手填音色 ID 和已有克隆音色。
- ElevenLabs 支持调节稳定度、音色相似度，以及独立的情绪和声音／语气标签开关；统一角色、模型默认音色与试听页的音色选择器。
- 新增「按概率触发」语音，支持 0–100% 概率设置，适用于私聊、主动消息和群聊。

### 插件管理

- 本地插件页支持通过安装链接预览、下载和安装插件，自动检查更新并提示升级。
- 升级时保留插件配置、启用状态和运行数据，加载失败时自动恢复旧版，支持安装与升级中断恢复。
- 本地插件详情页新增卸载入口，自动检查依赖关系并清理插件文件、配置及目录内的运行数据。
- 公网登录后支持查看、配置、启停和重载插件；优化配置面板的自适应高度、主题显示与编辑草稿保留。

### 聊天与界面

- 消息菜单新增「复制」，支持复制消息正文和语音转写文字。
- 聊天和朋友圈支持切换页面后恢复未发送的文字与附件，聊天草稿同时保留引用和 @成员，会话列表显示草稿摘要。
- 统一按钮、表单、账号卡片和主题控件样式，优化提示词输入框的自动高度与光标跟随、表情分类标签及手机竖屏和深色主题显示。
- 世界书支持在开头或末尾添加小节，展开与折叠时保持阅读位置。

### 修复与优化

- 微信 iLink 对齐 2.4.9，优化扫码登录、网络错误提示、消息轮询和输入状态刷新，修复旧扫码结果干扰新登录流程的问题。
- 修复微信图片与文件上传重复重试、损坏附件被保存的问题，完善扫码与连接诊断日志。
- QQ 对齐 `openclaw-qqbot@2.0.4` 协议处理，修复发送失败被误判成功、凭据重复刷新和错误重试，优化会话恢复、重连、账号停止处理及请求诊断日志。
- 对话上下文保留历史图片、文件和引用附件及其来源，修复后续回复丢失媒体上下文或混淆附件归属的问题。
- 修复角色导出后再导入时空系统指令、参考图模式、世界书顺序和提示词空白发生变化的问题，清理导入导出中的本机群记忆关联。
- 修复快速配置或新建会话后列表未刷新、角色设置部分生效、页面切换后旧请求覆盖内容，以及发送消息覆盖新草稿的问题。
- 精简常规 HTTP 请求与连接日志。

## [0.2.2] - 2026-09-27

### 角色语音控制

- MiniMax / PawAPI 支持语言、语速、音量和音调设置，粤语音色自动匹配粤语；MiMo 支持方言、语速档位和风格描述。
- 新增语气词、情绪和停顿开关，并将相应规则用于语音生成；文字回复自动清理语音控制标记。
- 语音测试支持调整参数并试听，角色语音设置支持局部更新和导入导出，切换服务商时保留各自参数。
- 完善 PawAPI 语音参数适配与调用错误提示。

### 记忆

- 新增「仅按轮数总结」，达到设定轮数后自动总结；触发轮数为 0 时关闭自动总结。
- 统一三种触发方式的设置说明，切换总结模式时保留处理进度。
- 统一 AI、网页、朋友圈和自动总结的记忆去重，按去除首尾空白后的文本精确比较。
- 记忆编辑与删除新增内容指纹校验，修复后台合并后编号变化导致更新错条目的问题；网页编辑冲突时保留草稿。
- 优化记忆写入、总结进度和提醒计数的保存顺序，修复设置变化后旧任务继续写入的问题。

### 聊天历史

- 聊天页支持每次加载 60 条历史消息，使用动态高度虚拟列表显示长会话。
- 修复上滑时被拉回底部、快速滚动时闪烁移位，以及图片和语音转写展开后阅读位置变化的问题。
- 新消息增量更新，查看历史时显示「回到底部」按钮与新消息数量；断线重连后自动补齐消息。
- 历史编辑、删除或清空后自动重载列表。

### QQ 主动消息

- 开放 QQ C2C 私聊主动推送，使用角色的随机间隔、连续上限和静默时段设置。
- 定时消息、插件主动发送及超出被动回复额度的发送共用频率控制与冷却机制。
- 优化主动消息的上下文选择、账号重启处理和等待取消。

### 通道修复

- 微信 / QQ 新增持久化引用索引，支持引用原消息中的图片和文件，并显示失效附件。
- 微信扫码支持已绑定提示，凭据失效冷却状态可跨重启保留。
- QQ 大文件支持分片上传，补齐大小预检、进度通知和重试。
- 修复重复入站、插件改派角色后的引用归属、历史编辑丢失引用附件，以及账号停止后旧请求继续发送的问题。

## [0.2.1] - 2026-08-16

### 新增与调整

- 新增 MiMo 语音服务商预设，支持内置音色、情绪表达、WAV 输出与各通道播放。
- 角色记忆新增「AI 自主记录＋按轮数总结」，自动总结未处理对话并保存进度。
- MCP 服务器支持设置工具超时（1–600 秒），用于普通工具调用及能力适配器，JSON 导入同步支持。
- 默认上下文轮数由 10 提升至 20。
- 主动消息连续失败 3 次后暂停，用户再次发言或重启程序后恢复；微信发送前检查回复窗口与配额。

### 更新安装

- 程序文件采用分阶段替换，失败时恢复旧版；启动时恢复中断的安装，资源文件合并到现有数据目录。
- 修复重复下载、下载进度回跳和已有更新包再次下载的问题。
- 优化更新弹窗的关闭方式和按钮文案。
- 修复文件占用时复制重试未生效的问题。

## [0.2.0] - 2026-07-27

### 聊天通道

- 新增 QQ C2C 私聊通道，支持文本、图片、视频、文件、语音及引用上下文。
- 插件可注册聊天通道，通过 `ctx.channels` 接收消息和投递回复。
- 添加账号和快速配置支持选择微信、QQ 或插件通道，账号列表显示所属通道。
- 统一通道生命周期、回复分发与主动推送策略，会话绑定改用 `channel_link`。
- 微信 iLink 协议更新至 2.4.6，支持保存扫码线路；优化 QQ 网关恢复、长文本分段与上传文件名。

### 语音

- 新增 AI 语音回复，支持文字与语音交替发送、情绪标记和合成失败后的文字回复。
- 新增 MiniMax、OpenAI 兼容及 PawAPI 语音服务商管理，支持模型、音色设置和试听。
- 微信 / QQ 入站语音可在网页播放、展开转写；对话上下文使用统一语音转写格式。
- QQ 支持 SILK 语音气泡，微信使用音频文件卡片，网页提供语音条播放。

### 记忆

- 新增 `record_memory` / `update_memory` 工具，AI 可自主记录或更新记忆。
- 达到提醒轮数后提示 AI 回顾对话，超出记忆容量时后台合并。
- 完善记忆内容、长度和配置校验，修复保存失败后仍提示成功的问题。

### 界面与配置

- 点击聊天头像可打开角色详情或个人资料。
- 快速配置新增隐私说明和遥测选项，遥测默认关闭。
- 优化本地静态资源与聊天媒体缓存，修复更新后页面资源未刷新、气泡塌缩和滚动位置变化的问题。
